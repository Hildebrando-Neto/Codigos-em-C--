# Fundamentos de Programação

Repositório criado para armazenar exercícios e práticas dos fundamentos
de programação desenvolvidos durante minha formação.

## Conteúdos

- Sequencial
- Condicionais
- Repetição
- Vetores
- Matrizes

## Tecnologias

- C++
- Qt Creator

## Objetivo

Registrar minha evolução em programação e manter organizados os exercícios
desenvolvidos durante meus estudos.
