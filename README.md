# 💻 Fundamentos de Programação

📚 Repositório criado para armazenar exercícios e práticas desenvolvidos durante
meus estudos de **Fundamentos de Programação**.

Os exercícios foram desenvolvidos utilizando **C++** e a IDE **Qt Creator**,
principalmente durante o início da minha trajetória na programação. 🚀

---

## 📂 Conteúdos

### 🔢 Sequencial
Exercícios envolvendo entrada de dados, processamento e saída de informações.

### 🔀 Condicionais
Práticas utilizando estruturas de decisão, como `if`, `else` e `switch`.

### 🔁 Repetição
Exercícios utilizando estruturas de repetição, como `for`, `while` e `do while`.

### 📦 Vetores
Exercícios envolvendo armazenamento e manipulação de dados utilizando vetores.

### 🧮 Matrizes
Práticas com matrizes e manipulação de dados em estruturas bidimensionais.

---

## 🛠️ Tecnologias utilizadas

- 💻 **C++**
- 🖥️ **Qt Creator**
